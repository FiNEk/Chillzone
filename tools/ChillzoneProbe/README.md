# ChillzoneProbe — проверка канала игры

Маленький отдельный аддон для проверки перед тем, как общий чат `/cz1` пойдёт через канал игры (этап 0 плана). Для игры он не нужен и в архив релиза Chillzone не входит.

С сетью Chillzone аддон не связан: не шлёт аддон-сообщений, ключей, подписей и переписи не трогает. Он входит только в тестовый канал `ChillzoneProbe`, отправляет туда строки, которые вы попросите, и записывает в журнал всё, что видит в этом канале. Журнал копируется из окна аддона одним отчётом.

Отчёт содержит имена участников проверки, тексты проверочных строк, номера каналов, зону и версию клиента. Ключей, паролей и чужой переписки в нём нет: строки других каналов аддон не записывает.

## Установка

1. Скачайте файлы ветки (на GitHub: Code, затем Download ZIP) и скопируйте папку `tools/ChillzoneProbe` в `Interface/AddOns` клиента, рядом с папкой `Chillzone`.
2. Включите «Chillzone Probe» в списке аддонов. Chillzone выключать не нужно.
3. В игре: `/czp help` — список команд, `/czp` — окно журнала.

## Кто нужен

Два-три игрока одной фракции из разных гильдий. Один из них — без ChillzoneProbe (лучше и без Chillzone): так видно, что получает обычный игрок. Ведущий — тот, кто войдёт в канал первым: он станет владельцем канала.

## Порядок проверки

Перед началом у всех с аддоном: `/czp clear`. Журнал сохраняется между входами в игру (последние 1500 строк), поэтому отчёт можно снять в самом конце.

**1. Вход и номера каналов.**
- Ведущий: `/czp join`. Затем остальные с аддоном: `/czp join`. Игрок без аддона: `/join ChillzoneProbe`.
- В журнале строки «вход в канал ... каналы до входа» и «через 3 с после входа в канал ... каналы»: изменились ли номера «Общий», «Торговля» и других каналов игры. «Окна с ним» показывает, появился ли канал в окнах чата сам.
- Выйдите из игры и войдите снова (не `/reload`). В журнале «при входе в мир», «через 5 с», «через 20 с»: вернула ли игра канал сама, под каким номером и не встал ли он перед каналами игры. Если встал, `/czp last` пробует переставить его в конец.

**2. Отправка из кода аддона (главная проверка).**
- В окне `/czp` напишите текст в поле внизу и нажмите Enter: путь «поле».
- Тот же текст кнопкой «Отправить»: путь «кнопка».
- В обычном чате `/czp привет`: путь «слэш».
- У получателей: дошла ли строка. У игрока без аддона: видна ли она в окне чата.
- В журнале автора на каждую отправку: «эхо #N (путь) ... совпало» или «нет эхо #N».

**3. Несколько отправок за одно нажатие.**
- `/czp multi 3 части` в обычном чате и `multi 3 части` в поле окна.
- Сколько частей дошло: (1/3), (2/3), (3/3), есть ли у автора «игра заблокировала» или «система: ...».

**4. Текст байт в байт.**
- `/czp kit` четыре раза (или кнопка «Набор»): кириллица и «кавычки», знаки ASCII, двойные пробелы и пробел в конце, строка ровно 255 байт.
- Ссылка: щёлкните в поле окна, затем Shift+щелчок по предмету в сумке и Enter. То же в обычном чате после `/czp `.
- Слово, которое заменяет фильтр брани: напишите его в поле. Включён ли фильтр у вас, видно в шапке отчёта.
- Игрок без аддона пишет в канал сам (`/номер текст`): у остальных появляется «приём от ...».
- Сравнение: у автора «отправка #N ... N байт, сумма ...», у получателей «приём от ... N байт, сумма ...». Если суммы разные или у автора «ИЗМЕНЕНО», строка изменилась в пути, и журнал показывает, с какого байта.

**5. Отправка из таймера (для сравнения).**
- `/czp timer 1 из таймера` и `/czp timer 0 следующий кадр`.
- Ожидается, что игра такую отправку не пропустит: «игра заблокировала ...» или «нет эхо». Если игра покажет окно о заблокированном действии аддона, закройте его и сделайте `/reload`. Если строка всё же дошла, это важно отметить.

**6. GUID и класс.** В строках «приём от ...» стоит «GUID есть, класс ...» или «без GUID».

**7. Подземелье.**
- Войдите в подземелье. В бою с боссом (или в ключе, на арене) отправьте из поля и через `/czp`.
- В журнале: «блокировка да» или «нет», результат отправки, эхо. У получателей в подземелье: «строка нашего канала со скрытыми полями».
- После выхода из боя и из подземелья — ещё раз.

**8. Права в канале.** Пароль и бан — последними, они могут закрыть канал для остальных.
- `/czp owner` — кто владелец (в журнале «CHANNEL_OWNER»).
- Не владелец по очереди: `/password ChillzoneProbe 123`, `/ban ChillzoneProbe Имя`, `/ckick ChillzoneProbe Имя`, `/moderator ChillzoneProbe Имя`, `/mute ChillzoneProbe Имя`, `/owner ChillzoneProbe Имя`, `/announce ChillzoneProbe`. Какой команды нет и что ответила игра — запишите.
- Владелец делает то же и отменяет: `/unban`, `/unmute`, `/password ChillzoneProbe` без пароля. Пришли ли уведомления остальным (в журнале «уведомление ...»).
- Владелец выходит: `/czp leave`. Кому перешёл канал («OWNER_CHANGED»).
- Игрок без аддона: видит ли он сообщения о входе и выходе участников, и пропали ли они после `/announce ChillzoneProbe` у владельца.

**9. Фильтр строк и `/cast`.**
- `/czp filter on`, затем отправка из поля и через `/czp`, сразу после неё макрос с `/cast <заклинание>` и `/target <имя>`.
- Не появилось ли окно о заблокированном действии; в журнале не должно быть «игра заблокировала».
- `/czp filter off`, затем `/czp hide` (убрать канал из окон чата) — то же самое. `/czp show` возвращает канал в первое окно.

**10. Отчёт.** `/czp copy` (или «Копировать отчёт»), затем Ctrl+A и Ctrl+C. Пришлите текст ведущему проверки.

## Что заполнить по результатам

| Вопрос | Где в журнале | Если ответ «нет» |
|---|---|---|
| Доходит ли строка из своего поля по Enter и из слэш-команды | шаг 2: «эхо ... совпало», «приём от» у получателей | канал годится только для набранного в штатном чате, этап 1 отменяется |
| Проходят ли 2–3 отправки за одно нажатие | шаг 3: части (1/3)–(3/3), «эхо» по пути «x3» | в канал уходит только первая часть длинной строки |
| Совпадает ли текст байт в байт | шаг 4: суммы, «ИЗМЕНЕНО» | сравнение копий по нормализованному тексту |
| Работает ли отправка в подземелье при блокировке | шаг 7: «блокировка да», эхо | в блокировке строка идёт только подписанным путём |
| Кто владелец, что может посторонний | шаг 8: «уведомление», «система», «ошибка игры» | до этапа 2 нужна защита канала |
| Видны ли вход и выход игрокам без аддона, выключаются ли | шаг 8, наблюдение игрока без аддона | учесть в инструкции для игроков без аддона |
| Сдвигает ли вход номера каналов игры, появляется ли канал в окне сам | шаг 1: «каналы», «окна с ним» | оставить перестановку из прежнего `Channel.lua` либо убрать |
| Есть ли GUID и класс | шаг 6 | строки без цвета класса |
| Работают ли `/cast` и `/target` после фильтра | шаг 9 | вместо фильтра — удаление канала из окон |
| (контроль) Проходит ли отправка из таймера | шаг 5 | ожидаемо: не проходит |

Предел участников канала и частотный лимит на двух-трёх игроках не проверить: их покажет этап 1.

## Команды

| Команда | Что делает |
|---|---|
| `/czp` | окно журнала |
| `/czp join [канал] [пароль]` | войти (по умолчанию `ChillzoneProbe`); дальше аддон входит сам после каждого входа в игру |
| `/czp leave` | выйти и больше не входить самому |
| `/czp текст`, `/czp say текст` | отправить из слэш-команды |
| `/czp multi N текст` | N строк (до 5) за одно нажатие |
| `/czp kit` | следующая строка проверочного набора |
| `/czp timer [секунд] текст` | отправка из таймера, для сравнения |
| `/czp state` | номер канала, окна, блокировка, список каналов |
| `/czp owner`, `/czp members` | владелец канала, участники |
| `/czp filter on`, `/czp filter off` | фильтр строк канала в окнах чата |
| `/czp hide`, `/czp show` | убрать канал из окон чата, вернуть в первое окно |
| `/czp last` | переставить канал за каналы игры |
| `/czp copy`, `/czp clear` | отчёт для копирования, очистка журнала и счётчиков |

В поле окна, кроме текста, работают `multi N текст` и `kit`.

## Удаление

`/czp leave`, затем удалите папку `ChillzoneProbe` из `Interface/AddOns`. Сохранённый журнал лежит в `WTF/Account/<учётная запись>/SavedVariables/ChillzoneProbe.lua`, его тоже можно удалить.
