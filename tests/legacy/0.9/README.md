Снимок Config.lua, Util.lua, Security.lua, Relay.lua и Census.lua из тега v0.9.0 для проверки
настоящего старого формата сертификатов, каталогов, поведения выдачи и выборов репортёра.
Файлы не меняются при развитии текущего протокола. Остальные модули симулятор загружает из
текущей версии: их транспортный формат S1/KP/RP/RR сохранён, а старые настройки регистрируют
только префикс CHZSIGNED1. Игровой интерфейс старого клиента в этих сценариях не открывается.
